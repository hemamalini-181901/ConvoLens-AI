# 🎙️ ConvoLens AI

### Hear More. Understand Better.

ConvoLens AI is an AI-powered conversation recording and analysis web application designed to help users capture conversations, view speech transcripts, and organize important information from discussions.

## ✨ Features

- 🎤 **Audio Recording** — Record conversations directly through your device's microphone.
- 📝 **Live Transcription** — Display recognized speech while recording, depending on browser support.
- ⏱️ **Session Timer** — Track the duration of a recording session.
- 💾 **Download Recordings** — Save recorded audio for later reference.
- 📄 **Transcript Export** — Download recognized conversation text.
- 🌌 **Modern UI** — Futuristic interface with a dark theme, gradients, and responsive layouts.
- 🔒 **Privacy Awareness** — Microphone access requires user permission.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Web MediaRecorder API
- Web Speech API

## 🚀 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/hemamalini-181901/ConvoLens-AI.git
   ```

2. Open the project folder:

   ```bash
   cd ConvoLens-AI
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

4. Allow microphone access when prompted and test the recording features.

## ⚙️ Browser Compatibility

ConvoLens AI uses browser audio and speech-recognition features. Support varies across browsers. Speech recognition may require an internet connection, and microphone access generally requires HTTPS or localhost.
